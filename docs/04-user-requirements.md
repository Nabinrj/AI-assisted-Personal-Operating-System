# User Requirements

## Primary user story
As a user, I want to see whether my daily actions are aligned with my long-term goals.

## User stories
- I can define a vision and break it into smaller goals.
- I can assign deadlines, priorities, and measurable success criteria.
- I can create projects and next actions.
- I can log actual time spent.
- I can track skills using evidence rather than arbitrary percentages.
- I can record income and financial milestones.
- I can perform daily and weekly reviews.
- I can see when my behavior contradicts my stated priorities.
- Later, I can ask an AI coach to analyze my history.

## User journey
Onboarding → define goals → choose 90-day sprint → create weekly objectives → schedule daily actions → log results → review → adjust plan.
