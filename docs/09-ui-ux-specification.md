# UI/UX Specification

## Main navigation
Dashboard | Goals | Tasks | Projects | Skills | Time | Money | Research | Analytics | Reviews | Settings

## Dashboard
Show current 90-day mission, today’s priority, execution score, deep-work progress, active projects, upcoming milestones, and reality-check alerts.

## Design principles
- Information hierarchy over decoration.
- One primary action per screen.
- Fast daily logging.
- Progress must be evidence-based.
- Mobile responsive, desktop optimized.
- Avoid meaningless motivational UI.

## Key screens
1. Onboarding and goal setup
2. Command Center
3. Goal tree
4. Project detail
5. Daily planner
6. Time log
7. Skill evidence
8. Weekly review
9. Analytics
10. Reality-check report

Wireframes are intentionally postponed until requirements stabilize.
