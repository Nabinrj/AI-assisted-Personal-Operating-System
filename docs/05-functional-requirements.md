# Functional Requirements

## Auth
Register, login, logout, token refresh, password hashing.

## Goals
CRUD goals; parent-child hierarchy; status; priority; target date; measurable outcome.

## Tasks
CRUD tasks; link to goal/project; due date; priority; status; estimated and actual effort.

## Projects
CRUD projects; objective; status; deadline; next action; blockers; repository URL; lessons learned.

## Skills
Current level, target level, evidence items, milestones, next action.

## Time
Create categorized entries: deep work, learning, building, research, gaming, scrolling, exercise, sleep, other.

## Money
Record income entries, source, amount, currency, date, milestone.

## Reviews
Daily prompts and weekly retrospective with wins, failures, blockers, metrics, and next-week priority.

## Analytics
Daily/weekly/monthly summaries, execution rate, time distribution, goal progress, project status.

## Reality checks
Rules should flag conditions such as excessive distraction time, no progress on active projects, and repeated planning without execution.
