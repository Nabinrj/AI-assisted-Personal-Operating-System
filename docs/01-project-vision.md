# Project Vision

## Vision
Create a system that helps ambitious people translate distant goals into measurable present actions and exposes the gap between what they claim to value and how they actually spend their time.

## Problem
Most productivity tools manage tasks but do not connect daily behavior to long-term goals. People can appear busy while moving nowhere.

## Solution
NABU creates one chain:
Vision → Objectives → Yearly targets → 90-day sprint → Monthly milestone → Weekly objective → Daily action → Evidence → Review.

## Product principles
1. Evidence beats self-reported motivation.
2. Every important task must connect to a higher objective.
3. The system should expose contradictions, not flatter users.
4. Research and planning have limits; execution produces evidence.
5. AI analyzes data and recommends actions; it does not control the user.

## Initial target user
The first user is the founder. After 90 days of real use, determine whether the system solves a broader market problem.
