# Development Roadmap

## Phase 0 — Foundation (Days 1–3)
Repository, README, monorepo structure, Docker, environment configuration, CI.

## Phase 1 — Core Data (Week 1)
FastAPI, PostgreSQL, migrations, auth, users.

## Phase 2 — Goals and Tasks (Week 2)
Goal hierarchy, milestones, tasks, daily priority.

## Phase 3 — Projects and Skills (Week 3)
Project tracker, blockers, next action, skill evidence.

## Phase 4 — Time and Reviews (Week 4)
Time logging, daily check-in, weekly review.

## Phase 5 — Dashboard and Analytics (Week 5)
Command Center, charts, execution calculations, reality checks.

## Phase 6 — Polish and Deployment (Week 6)
Testing, responsive UI, error handling, deployment.

## Phase 7 — AI Coach
Only after 30–90 days of useful structured data exist.
