# Product Requirements Document

## Product
NABU — AI-Assisted Personal Operating System

## Goal
Help users continuously convert long-term ambitions into measurable execution and review.

## MVP success criteria
- A user can create a goal hierarchy.
- A user can create projects and link them to goals.
- A user can plan and complete daily tasks.
- A user can log deep work, research, entertainment, and other time.
- The dashboard shows planned versus actual behavior.
- The user can complete daily and weekly reviews.
- The system stores evidence for completed skills and milestones.

## Non-goals for MVP
- Social networking
- Team collaboration
- Full financial accounting
- Mobile app
- Autonomous AI agents
- Complex gamification

## Primary KPI
Weekly execution rate = completed planned work ÷ planned work.

## Secondary KPIs
Deep-work hours, project completion rate, milestone completion, income progress, review consistency, and planned-vs-actual time alignment.
