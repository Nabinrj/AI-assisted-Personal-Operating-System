# API Design

Base: /api/v1

## Auth
POST /auth/register
POST /auth/login
POST /auth/refresh
GET /auth/me

## Goals
GET/POST /goals
GET/PATCH/DELETE /goals/{id}

## Projects
GET/POST /projects
GET/PATCH/DELETE /projects/{id}

## Tasks
GET/POST /tasks
GET/PATCH/DELETE /tasks/{id}

## Skills
GET/POST /skills
PATCH/DELETE /skills/{id}
POST /skills/{id}/evidence

## Time
GET/POST /time-entries
PATCH/DELETE /time-entries/{id}

## Income
GET/POST /income
PATCH/DELETE /income/{id}

## Reviews
GET/POST /reviews/daily
GET/POST /reviews/weekly

## Analytics
GET /analytics/dashboard
GET /analytics/weekly
GET /analytics/time

OpenAPI is generated by FastAPI. Response schemas and error codes must be defined before frontend integration.
