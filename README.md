# NABU — AI-Assisted Personal Operating System

NABU is an AI-assisted Personal Operating System that converts long-term ambitions into measurable daily execution. It connects goals, milestones, tasks, projects, skills, time, income, research, reviews, and evidence in one feedback system.

## Core loop
Plan → Execute → Measure → Review → Adjust → Repeat

## MVP modules
- Command Center dashboard
- Hierarchical goals
- Daily and weekly tasks
- Project execution tracker
- Skill matrix with evidence
- Time and distraction tracking
- Income tracking
- Daily check-ins and weekly reviews
- Reality-check analytics

## Stack
React + TypeScript + Tailwind CSS | FastAPI | PostgreSQL | JWT | Docker. AI analysis is added after the core product works.
