# Sprint 2 — Goals and Tasks

## Objective
Implement the hierarchy that converts long-term objectives into executable tasks.

## Deliverables
- Goal CRUD
- Parent/child goal hierarchy
- Milestones
- Task CRUD
- Goal/project links
- Priority and status
- Daily priority selection

## Done when
A user can create a long-term goal, break it into smaller goals and milestones, attach tasks, complete work, and see progress update.
