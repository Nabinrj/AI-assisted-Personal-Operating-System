# Sprint 3 — Projects, Skills and Evidence

## Objective
Track meaningful capability growth and project execution using evidence rather than arbitrary self-ratings.

## Deliverables
- Project CRUD
- Status, blockers and next action
- Goal links
- Repository URL
- Skill CRUD
- Skill evidence
- Milestones and completion history

## Done when
A user can connect completed project work and evidence to goals and skills.
