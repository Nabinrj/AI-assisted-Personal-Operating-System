# Sprint 7 — AI Coach

## Status
BLOCKED until meaningful structured usage data exists.

## Objective
Use AI to analyze real execution patterns and produce evidence-based recommendations.

## Candidate features
- Weekly analysis
- Goal-to-behavior contradiction detection
- Blocker pattern analysis
- Next-action recommendations
- Structured summaries

## Constraint
The AI must not invent user history or replace deterministic calculations. It should cite the underlying data points used in its analysis.

## Entry criterion
At least 30–90 days of real usage data from the core system.
